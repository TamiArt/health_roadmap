# PWA, мобильная версия и доступность

## Установка

Приложение публикуется как PWA и должно открываться по HTTPS (или на localhost при локальной разработке).

- **Android (Chrome):** откройте приложение в браузере → меню браузера → «Установить приложение» или «Добавить на главный экран».
- **iPhone / iPad (Safari):** откройте приложение в Safari → «Поделиться» → «На экран Домой» → подтвердите добавление.
- После установки приложение запускается в отдельном окне. Для iOS используется touch-иконка и режим standalone из web app manifest.

Установка зависит от браузера и его критериев PWA. Наличие кнопки установки не гарантируется внутри встроенных браузеров социальных сетей.

## Работа при нестабильном интернете

- Service worker сохраняет оболочку приложения, manifest, иконки и production JS/CSS/assets из Vite build manifest.
- Навигация использует network-first: при доступной сети браузер получает актуальную страницу; при потере сети открывается сохранённая оболочка.
- Статические ресурсы обслуживаются cache-first после первого получения.
- Запросы /api/ намеренно не кэшируются: медицинские данные, сессии и ответы сервера не помещаются в общий Cache Storage.
- Медицинские записи продолжают сохраняться локально в IndexedDB. При аккаунте синхронизация ставит изменения в очередь и повторяет отправку после события online; конфликты не перезаписываются автоматически.
- Первый запуск и первая загрузка ресурсов требуют подключения. Для полноценной автономной работы приложение нужно хотя бы один раз открыть онлайн; синхронизация между устройствами требует интернета.

## Мобильная и планшетная адаптация

- На телефонах основная навигация закреплена снизу, с учётом safe-area iOS; на больших экранах используется боковая навигация.
- Для узких экранов поля медицинских форм перестраиваются в одну колонку, а размер текста полей не провоцирует автоматическое увеличение страницы в iOS Safari.
- Основные кнопки имеют увеличенную сенсорную область; горизонтальное переполнение проверяется на ширине 320, 360 и 390 px.
- На планшетах сохраняется боковая навигация и адаптивная ширина контента.

## Доступность и уведомления

- Основные разделы доступны с клавиатуры; есть ссылка перехода к основному содержимому и обозначение текущего раздела через aria-current.
- Состояния загрузки, ошибки, успешные операции, конфликты и потеря сети объявляются через role=status / role=alert и live regions.
- Учитывается системная настройка уменьшения анимации (prefers-reduced-motion).
- Интерактивные элементы имеют видимый фокус; формы используют подписи и доступные имена.

## Ограничения

PWA-кэш предназначен для статической оболочки и ресурсов, а не для резервного копирования медицинской информации. Локальные данные хранятся в IndexedDB текущего браузера/устройства; для доступа с другого устройства нужен вход в аккаунт и успешная серверная синхронизация. Уведомления браузера зависят от разрешений пользователя и возможностей установленного браузера/ОС.
