# Медицинская аналитика

## Назначение

Раздел «Аналитика здоровья» показывает динамику только тех значений, которые пользователь сохранил в выбранном профиле. Аналитика не создаёт медицинские данные, не распознаёт содержимое PDF/изображений и не рассчитывает диагнозы или общий индекс здоровья.

## Источники данных

- `labResultEntries`: числовые показатели подробных лабораторных исследований, включая введённые пользователем референсные диапазоны;
- `labMeasurements`: ручные измерения из каталога анализов;
- `healthMonitoring.measurements`: датированные значения показателей и наблюдений;
- `vaccineRecords`: количество сохранённых записей о вакцинации для сводки;
- `adultToothData` / `childHealth:<id>:toothData`: стоматологическая сводка;
- `vaccineStatuses`: статусы профилактической вакцинации.

Взрослые и детские записи читаются из отдельных ключей. Аналитика не меняет формат хранения, не переписывает исходные записи и не переносит данные между профилями.

## Группировка и сравнение

Лабораторные серии объединяются по нормализованным названию показателя и единице измерения. Измерения с другой единицей или другим названием остаются отдельными сериями. Нечисловые значения пропускаются при построении графиков, но остаются в исходной истории.

Для каждой серии рассчитываются абсолютное изменение и процентное изменение между первым и последним значениями выбранного периода. Если исходное значение равно нулю, процентное изменение не вычисляется.

## Референсные значения

Поддерживаются числовые диапазоны вида `3.5-5.5`, `3,5–5,5`, `< 5.2`, `≤ 5.2`, `> 4` и `от 4`. Односторонние границы (`< 5.2`, `≤ 5.2`, `> 4`, `≥ 4`, `до 5.2`, `от 4`) также отображаются на графике как граница и затенённая область. Свободный текст сохраняется и отображается, но не используется для автоматической классификации. Если для показателя сохранено только одно числовое значение, график показывает эту точку без расчёта динамики. Референсы принадлежат конкретному результату. Общая зона референса на графике отображается только тогда, когда одинаковый диапазон указан у всех точек серии; при различиях график не переносит норму последнего анализа на прошлые даты, а диапазон показывается рядом с каждой исходной записью. Приложение не пытается самостоятельно подбирать нормы по возрасту, полу, лаборатории или клиническому контексту.

## Фильтры и переходы

Доступны фильтры профиля, категории (лабораторные показатели / измерения и наблюдения), текстового запроса и диапазона дат. Для каждой исходной точки есть действие «Открыть запись»: подробные результаты открываются в истории анализов, ручные измерения — в каталоге анализов, измерения мониторинга — в разделе «На контроле» с прокруткой к соответствующей записи.

## Ограничения и безопасность интерпретации

- Загруженные документы не распознаются автоматически и не включаются в числовые серии.
- Референсные интервалы могут различаться между лабораториями и для разных клинических обстоятельств; приложение использует только явно сохранённое пользователем значение.
- Направление изменения (рост/снижение) само по себе не означает улучшение или ухудшение состояния.
- Графики — инструмент визуализации личной истории, а не медицинская рекомендация.
