# Life Maps — Документация приложения

> Навигатор человеческой жизни. Не показывает, где вы находитесь. Показывает, куда движется ваша жизнь.

---

## Реализованные функции (текущая версия)

### 🗺 Карта жизни

- Интерактивная вертикальная временна́я шкала с чередующимися карточками событий (левая/правая сторона).
- 17 событий жизни в диапазоне 1997–2024, охватывающих 7 категорий.
- Категории: Личное, Образование, Карьера, Путешествия, Здоровье, Семья, Достижения — каждая со своей цветовой схемой.
- Фильтрация событий по категории (клик на пилюлю-фильтр).
- Раскрытие события по клику: появляется описание с подробностями (анимация motion).
- Визуальное выделение ключевых событий (milestone): обводка, золотая звезда, тёмный узел на шкале.
- Узлы временной шкалы показывают две последние цифры года (`'97`, `'24`); milestone — тёмным фоном.
- Сводные цифры в шапке: лет жизни, событий, стран, достижений.
- Точечный фоновый паттерн в шапке — отсылка к картографической эстетике.

### ❤️ Навигатор здоровья

- Дорожная карта профилактики по возрастным точкам: 17 / 20 / 25 / 27 лет.
- Каждая точка — аккордеон: разворачивается по клику, показывает список чекапов.
- Для каждого чекапа: название, статус (выполнен / не выполнен), объяснение «почему это важно».
- Выполненные пункты зачёркнуты, невыполненные выделены как приоритетные.
- Текущий возраст (27) визуально отмечен: синий узел + тег «Сейчас».
- Полностью выполненные возрасты: зелёный узел.
- Три информационные карточки в шапке: следующий рекомендованный визит, последнее посещение, количество пунктов к выполнению.

### 💼 Карьера

- Хронологическая лента опыта: 5 записей от МГУ (2015) до Senior Researcher (2021–сейчас).
- Текущее место работы выделено тегом «Сейчас» и кольцом.
- Секция навыков: 6 компетенций с анимированными прогресс-барами (ширина анимируется при монтировании).

### 💰 Финансы

- 4 финансовых цели: Резервный фонд, Ипотека, Инвестиции, Фонд путешествий.
- Для каждой: текущая сумма, целевая сумма, процент выполнения.
- Анимированные прогресс-бары с индивидуальной цветовой схемой по цели.
- Суммы форматируются через `Intl.NumberFormat` в рублях.

### 👨‍👩‍👧 Семья

- 5 карточек членов семьи: имя, роль, возраст, эмодзи-аватар.
- 4 памятные даты с подробностями.

### 🎯 Цели

- 6 жизненных целей с прогресс-барами.
- Для каждой: категория (цветная пилюля), приоритет (Высокий / Средний / Низкий), дедлайн, процент выполнения.

### 📈 Аналитика

- **График «Качество жизни»**: AreaChart (recharts) по годам 2018–2024, субъективная оценка 0–100.
- **«Баланс жизни»**: RadarChart по 6 сферам (Здоровье, Карьера, Финансы, Отношения, Развитие, Хобби).
- **3 ключевых наблюдения**: карточки с коротким инсайтом по данным.

### Общее / UI

- Боковая навигация (sidebar) с 7 разделами.
- Профиль пользователя в sidebar: имя, возраст, город, «Индекс жизни» с анимированным прогресс-баром.
- Анимация при переключении разделов (fade + slide, motion/react).
- Картографическая эстетика: тёплый фон #F2EEE4, тёмный тил #2C5F5A, Playfair Display + Inter + DM Mono.
- Точечный фоновый паттерн (dot grid) в основном контейнере.
- Адаптивные сетки: `grid-cols-3 → grid-cols-1` через стандартные Tailwind-брейкпоинты.

## Планируемые функции (roadmap)

### Ближайший приоритет

| Функция | Описание |
|---|---|
| **Добавление событий** | Форма создания нового события: дата, заголовок, описание, категория, флаг milestone, фото |
| **Редактирование / удаление событий** | Контекстное меню или кнопки на карточке |
| **Реальное хранилище** | Замена статических массивов на SQLite (через Tauri/Electron IPC или IndexedDB в браузерной версии) |
| **Динамика показателей здоровья** | Графики изменения АД, веса, холестерина, глюкозы, витаминов по введённым анализам |
| **Медицинский архив** | Загрузка и хранение PDF-документов: анализы, УЗИ, заключения врачей |
| **Вакцинация** | Отдельный блок с историей прививок и напоминаниями |

### Средний горизонт

| Функция | Описание |
|---|---|
| **Карта путешествий** | Визуальная карта мира (react-simple-maps или MapLibre) с отметками посещённых стран/городов |
| **Хронология связей** | Граф или таймлайн знакомств: люди, повлиявшие на жизнь |
| **Детальная аналитика привычек** | Трекер ежедневных привычек + корреляция с «качеством жизни» |
| **Финансовая история** | График активов и доходов по годам; поддержка нескольких валют |
| **Экспорт** | Экспорт карты жизни в PDF / PNG; экспорт всех данных в ZIP-архив (JSON + медиафайлы) |
| **Импорт** | Импорт из ZIP-архива; импорт событий из Google Takeout, Apple Health |
| **Тёмная тема** | Полноценная `.dark`-схема с сохранением выбора |
| **Локализация** | Поддержка EN / RU / DE через i18next |

### Дальний горизонт

| Функция | Описание |
|---|---|
| **AI Assistant (локальный)** | Опциональный модуль: загрузка GGUF-модели (Qwen 3 4B / Gemma 3 4B / Phi-4 Mini), вопросы по своей жизни |
| **Семантический поиск** | sqlite-vec + локальные эмбеддинги для поиска по смыслу, а не только по тексту |
| **Генеалогическое дерево** | Интерактивный граф семьи с фотографиями и датами |
| **Медицинский AI-ассистент** | Персонализированные рекомендации по профилактике на основе локальных данных и возраста |
| **Нативные приложения** | React Native (iOS/Android), Tauri (Windows/macOS/Linux) |
| **Совместный доступ** | Опциональный шеринг отдельных событий или раздела «Семья» с близкими (P2P, без облака) |

## Логика работы

### Архитектура (текущая)

```
App (state: activeSection)
├── Sidebar           — навигация, профиль пользователя
└── Main (overflow-y-auto)
    ├── LifeMapSection
    │   ├── фильтр по категории (useState)
    │   └── expanded event (useState)
    ├── HealthSection
    │   └── открытый аккордеон (useState: index | null)
    ├── CareerSection
    ├── FinanceSection
    ├── FamilySection
    ├── GoalsSection
    └── AnalyticsSection
        ├── AreaChart (recharts)
        └── RadarChart (recharts)
```

Всё состояние — локальный React-стейт. Данные — статические константы в файле. При переключении раздела предыдущий компонент размонтируется, локальные стейты (раскрытые аккордеоны, фильтры) сбрасываются.

### Анимации

Используется `motion/react` (не `framer-motion`):
- `motion.div` с `initial / animate / transition` для появления карточек событий (stagger через `delay: i * 0.04`).
- Анимация ширины прогресс-баров при монтировании: `0% → N%`.
- Смена раздела: fade + slide вверх (`y: 10 → 0`, `opacity: 0 → 1`).
- `AnimatePresence` не используется (ограничение текущей конфигурации) — exit-анимации отсутствуют.

### Стили

Tailwind CSS + кастомные CSS-токены в `theme.css`. Шрифты подключены через Google Fonts в `fonts.css`:
- **Playfair Display** — заголовки разделов.
- **Inter** — основной текст интерфейса.
- **DM Mono** — цифровые данные, даты, проценты.

## Узкие места и ограничения

### Данные

- **Всё захардкожено.** Нет ни базы данных, ни API. Добавить событие через UI невозможно — только правкой исходного кода. Это прототип, а не рабочее приложение.
- **Нет персистентности.** При обновлении страницы всё состояние (раскрытые аккордеоны, выбранный фильтр) сбрасывается. Данные не сохраняются между сессиями.

### Производительность

- **Нет виртуализации списка событий.** Если событий станет 500+, DOM-рендер замедлится. Решение: `react-virtual` или `@tanstack/react-virtual`.
- **Recharts перерисовывается при каждом ре-рендере** родителя. Решение: `React.memo` на секции аналитики.
- **Анимации stagger** при большом количестве карточек создадут длинную задержку: при 100 событиях последняя карточка появится через 4 секунды.

### UX

- **Exit-анимации отсутствуют**: карточки при скрытии/фильтрации исчезают мгновенно без плавного перехода.
- **Нет состояния загрузки**: в реальном приложении с SQLite первый рендер будет асинхронным, нужен skeleton.
- **Sidebar не сворачивается**: на экранах < 1024px боковая панель (240px) отъедает слишком много места. Нужен collapsible sidebar или bottom navigation для мобильных.
- **Фильтр категорий сбрасывается** при переключении в другой раздел и возврате обратно (стейт не сохраняется).
- **Нет поиска по событиям** — при 100+ событиях навигация по карте жизни становится неудобной.

### Масштабируемость

- **Монолитный App.tsx** (~500 строк): все компоненты, типы и данные в одном файле. При росте функционала необходима декомпозиция на модули (`/sections`, `/components`, `/data`, `/types`).
- **Нет роутинга**: смена раздела через `useState` работает для прототипа, но не поддерживает deep-linking, history.back() и закладки браузера. Нужен `react-router`.
- **Нет управления состоянием**: при добавлении реальных данных и нескольких источников правды потребуется `zustand`, `jotai` или React Context.

### Здоровье / медицинский блок

- **Рекомендации статические и не персонализированные**: не учитывают пол (отдельного выбора нет), хронические заболевания, страну проживания, семейный анамнез. Для реального приложения нужен конфигуратор профиля.
- **Нет напоминаний**: приложение не может уведомить пользователя о том, что пора на осмотр. Для desktop-версии нужна интеграция с системными уведомлениями (Tauri: `tauri-plugin-notification`).
- **Не хранит реальные анализы**: нет загрузки файлов, нет ввода числовых показателей и построения динамики.

### AI-модуль

- **Отсутствует полностью** в текущей версии. Планируемая архитектура: llama.cpp как backend-процесс, общение через WebSocket или HTTP-localhost. Основные риски: модель 4B занимает ~3 GB RAM, первый запуск занимает 10–30 секунд, на слабых устройствах возможны зависания UI-потока.
