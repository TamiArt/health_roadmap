# Life Maps — обзор приложения

> Персональный навигатор жизненных событий, здоровья и семьи.

## Текущие разделы приложения

### 🗺 Карта жизни
- Временная шкала событий с чередованием карточек слева и справа.
- Фильтр «Ключевые / Все события», категории и цветовые метки.
- Просмотр, добавление, редактирование и удаление событий.
- Визуальное выделение важных событий и анимации появления карточек.

### ❤️ Навигатор здоровья
- Дорожная карта профилактики по возрастным этапам.
- Каталог лабораторных исследований с фильтром по полу и раскрывающимися группами.
- Локальный выбор файлов результатов анализов в текущей сессии.
- Карточки вакцинации с изменением статуса.
- Интерактивная стоматологическая карта FDI с заметками по зубам.

### 👨‍👩‍👧 Семья
- Карточки взрослых членов семьи.
- Добавление и удаление членов семьи, детей и памятных дат.
- Экран здоровья ребёнка с возрастным подбором этапов, анализов и вакцинации.

### 📈 Аналитика
- Приоритеты, рассчитываемые по статусам вакцинации.
- Сводные показатели вакцинации.
- Демонстрационный график динамики здоровья и этапы жизни.

## Архитектура и структура исходного кода

Точка входа: `src/main.tsx` → `src/app/App.tsx`.

```text
src/
├── main.tsx
├── app/
│   ├── App.tsx                 # корневой layout и переключение разделов
│   ├── Sidebar.tsx             # боковая навигация
│   ├── LifeMapSection.tsx      # карта жизненных событий
│   ├── HealthSection.tsx       # профилактика, анализы, вакцинация, стоматология
│   ├── FamilySection.tsx       # семья и экран здоровья ребёнка
│   ├── AnalyticsSection.tsx    # аналитика здоровья
│   ├── data.ts                 # типы и демонстрационные данные
│   └── shared.tsx              # общие константы, helpers и небольшие UI-компоненты
└── styles/
    ├── fonts.css
    ├── index.css
    ├── tailwind.css
    └── theme.css
```

### Потоки состояния
- Выбранный раздел и статусы вакцинации находятся в корневом компоненте `App`.
- Состояния редактирования, фильтров, раскрытых блоков, семейных карточек и зубной карты принадлежат соответствующим разделам.
- Основные пользовательские записи сохраняются в IndexedDB текущего браузерного профиля.
- Разделы, вкладки и профили сохраняют состояние при навигации; постоянные записи переживают перезагрузку страницы.

### UI и стили
- React 18 + TypeScript.
- Компоненты разделов реализованы напрямую на JSX без готового Figma UI-кита и без импортов из каталога шаблонных компонентов.
- Tailwind CSS 4 и CSS-переменные в `src/styles/theme.css`.
- Motion (`motion/react`) для анимаций.
- Recharts для графика в аналитике.
- Lucide React для иконок.
- Неиспользуемые shadcn/Radix UI-заготовки удалены; необходимые элементы интерфейса остаются локальными компонентами и CSS/Tailwind-разметкой.
- Шрифты Playfair Display, Inter и DM Mono подключаются через `src/styles/fonts.css`.

## Ограничения текущей версии

- Нет backend, API, авторизации, облачного хранилища или межустройственной синхронизации.
- Постоянное локальное хранилище реализовано на IndexedDB.
- Основные события, медицинские справочники, семейные данные и графики — демонстрационные константы.
- Изменения карты жизни, семьи, детских профилей, вакцинации и стоматологии сохраняются локально в IndexedDB.
- Файлы результатов анализов сохраняются как Blob; object URL создаются только для отображения и освобождаются при изменении/размонтировании.
- Медицинские тексты и статусы не являются проверенными персональными медицинскими рекомендациями.
- Автоматизированная проверка production-сборки выполняется GitHub Actions.

## План развития

1. Стабилизация и проверка воспроизводимой сборки.
2. Декомпозиция приложения без визуальных и функциональных изменений.
3. Отделение демонстрационных данных от пользовательских профилей и формализация моделей данных.
4. Выбор локального хранилища, резервное копирование и миграции.
5. Реализация пользовательских CRUD-сценариев и безопасного архива документов.
6. Тестирование доступности, адаптивности, приватности и пользовательских сценариев.

## Проверка качества

- `npm run typecheck` — строгая проверка TypeScript без генерации файлов.
- `npm test` — запуск unit-тестов Vitest.
- `npm run test:e2e` — браузерные E2E smoke-тесты Playwright (Chromium).
- GitHub Actions выполняет установку зависимостей, проверку типов, unit-тесты, Playwright E2E smoke-тесты (Chromium) и production-сборку при push в рабочую ветку и при pull request в `main`.

## Реализовано в ветке feat/local-first-data-platform

- Демонстрационные имена, даты и географические подробности в стартовых данных заменены нейтральными примерами.
- Удалено двойное отображение группы крови/резус-фактора и неонатального скрининга у младенцев; базовые исследования рождения больше не показываются старшим возрастным группам.
- Для повторяющихся исследований введены стабильные conceptId и отдельные read-model коллекции концептов и возрастных назначений.
- Пользовательские записи сохраняются в IndexedDB: карта жизни, семья, детские профили, статусы вакцинации, стоматологические данные и файлы анализов.
- Добавлены версионированные JSON-резервные копии, импорт с подтверждением замены текущих данных и кодирование Blob-вложений.
- Добавлены автоматические проверки tablet viewport 768 px, клавиатурной активации навигации, валидации создания ребёнка, перезагрузки и восстановления из резервной копии.
- CI проверяет лимит 1500 строк на исходный файл и выполняет npm audit.
- Межустройственная синхронизация, серверная БД, шифрование локальной базы и ручной accessibility-аудит не реализованы.
