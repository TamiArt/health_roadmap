# Life Maps — обзор приложения

> Локальный навигатор жизненных событий, медицинской истории и семейных профилей.

## Разделы приложения

### 🗺 Карта жизни
- Лента жизненных событий с категориями и ключевыми этапами.
- Добавление, редактирование и удаление пользовательских событий.
- Сохранение записей в IndexedDB.

### ❤️ Здоровье
- Профилактическая дорожная карта и каталог лабораторных исследований.
- Результаты анализов с датой, несколькими показателями, единицами измерения и вложенным документом.
- Вакцинация и стоматологические записи.
- Медицинские события: операции, травмы, переломы, диагнозы и другие записи.
- Раздел «На контроле» для пользовательских показателей, дат следующей проверки и истории измерений.

### 👨‍👩‍👧 Семья
- Карточки взрослых членов семьи и детские профили.
- Отдельные медицинские данные каждого ребёнка.
- Памятные даты с ежегодным повторением и настройками напоминаний.
- При удалении профиля ребёнка его медицинские записи удаляются вместе с сохранением ревизионных tombstone-маркеров.

### 🗓 Календарь
- Общая месячная сетка событий из разделов здоровья, анализов, контроля и семьи.
- Фильтры по источникам, отметки дней с событиями и список событий выбранной даты.
- Отображение профиля, которому принадлежит запись.
- Календарь агрегирует существующие записи и не создаёт отдельную копию данных.

### 📈 Аналитика
- Сводные показатели на основе сохранённых пользовательских данных.
- Разделение данных взрослого и детских профилей.
- Медицинские показатели не интерпретируются как диагноз или персональная рекомендация.

## Локальное хранение и резервные копии

Пользовательские данные хранятся в IndexedDB текущего браузерного профиля. Серверная база данных и синхронизация между устройствами не подключены.

- Для записей используются ревизии, чтобы устаревшая вкладка не перезаписывала более новые данные.
- Межвкладочные обновления передаются через BroadcastChannel.
- Резервная копия экспортируется в JSON; вложенные Blob-файлы кодируются для переноса.
- Импорт проверяет формат, версию и структуру данных перед заменой текущего локального набора.
- Медицинские данные детей хранятся под отдельными ключами `childHealth:<id>:`.

Данные браузера могут быть потеряны при очистке хранилища или удалении профиля браузера. Регулярно сохраняйте резервные копии в отдельном безопасном месте.

## Технологии и структура

React 18, TypeScript, Vite, Tailwind CSS 4, Motion, Recharts, Lucide, Vitest и Playwright.

Точка входа: `src/main.tsx` → `src/app/App.tsx`.

Основные модули приложения находятся в `src/app/`. Общие правила структуры и текущий план этапов разработки описаны в [TECHNICAL_ROADMAP.md](./TECHNICAL_ROADMAP.md).

## Проверки

- `npm run typecheck` — проверка TypeScript.
- `npm run check:structure` — проверка структуры и ограничения размера исходных файлов.
- `npm test` — unit-тесты.
- `npm run test:e2e` — браузерные сценарии Playwright.
- `npm run build` — production-сборка.

GitHub Actions запускает проверки на Ubuntu 24.04 и Node.js 22. Runner закреплён на Ubuntu 24.04, поскольку зафиксированная версия Playwright 1.56.1 не содержит browser package для Ubuntu 26.04.

## Ограничения

- Данные доступны только в текущем браузерном профиле и не синхронизируются между устройствами.
- Браузерные напоминания зависят от разрешений и возможностей браузера; приложение не гарантирует фоновую доставку уведомлений.
- Медицинские справочники и примеры носят информационный характер и не заменяют консультацию специалиста.
