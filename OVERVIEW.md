# Life Maps — обзор приложения

> Персональный навигатор жизненных событий, здоровья и семьи.

## Разделы приложения

### 🗺 Карта жизни
- Временная шкала событий с категориями и ключевыми этапами.
- Просмотр, добавление, редактирование и удаление событий.
- Сохранение пользовательских событий в IndexedDB.

### ❤️ Навигатор здоровья
- Дорожная карта здоровья по возрастным этапам.
- Каталог лабораторных исследований с фильтрами и назначениями по этапам.
- Добавление, редактирование и удаление ручных результатов анализов.
- Загрузка файлов результатов анализов.
- Карточки вакцинации с изменением статусов.
- Интерактивная стоматологическая карта FDI с заметками по зубам.

### 👨‍👩‍👧 Семья
- Карточки взрослых членов семьи.
- Создание и удаление членов семьи, детей и семейных событий.
- Отдельные детские профили с подбором этапов лабораторных исследований и вакцинации.
- Изоляция медицинских записей между детскими профилями.

### 📈 Аналитика
- Сводка статусов вакцинации из сохранённых данных.
- Количество ручных результатов анализов, исследований, загруженных файлов и стоматологических записей.
- Последние введённые результаты анализов.
- Переключение между взрослым профилем и каждым детским профилем.
- Демонстрационная оценка здоровья и фиктивный график удалены; приложение не рассчитывает общий медицинский балл.

### Модель лабораторного каталога

- `LAB_TEST_CONCEPTS` содержит 42 канонических концепта исследования.
- `LAB_TEST_ASSIGNMENTS` содержит 57 возрастных/тематических назначений.
- `LAB_TEST_STAGE_DEFINITIONS` содержит метаданные 10 этапов.
- `getLabStages()` и `getLabStage()` формируют read-model по запросу из канонических сущностей.
- `LIFE_STAGES` сохранён для обратной совместимости; feature-компоненты используют селекторы.
- Идентификаторы назначений стабильны и используются как ключи сохранённых результатов.

### Общие доменные модели

`models.ts` содержит типы жизненных событий, членов семьи, детских профилей, семейных событий, вакцинации, стоматологических статусов, `DentalRecord`, лабораторных измерений, файлов результатов и аналитических данных. Доменные конфигурации и фикстуры вынесены в `lifeMapData.ts`, `healthData.ts`, `familyData.ts` и `analyticsData.ts`. `data.ts` сохранён как тонкий слой совместимости; feature-компоненты импортируют данные напрямую из доменных модулей.

## Потоки состояния и хранение

- Основные пользовательские записи сохраняются в IndexedDB текущего браузерного профиля.
- Записи имеют ревизии; устаревшие изменения не должны перезаписывать более новую версию.
- Изменения между вкладками передаются через BroadcastChannel.
- Детские медицинские записи используют ключи с идентификатором ребёнка.
- Разделы, вкладки и профили сохраняют состояние при навигации.
- Файлы результатов хранятся как Blob; object URL создаются для отображения и освобождаются при изменении/размонтировании.

## Ограничения текущей версии

- Нет backend, API, авторизации, облачного хранилища или межустройственной синхронизации.
- Часть начальных данных и графиков демонстрационная.
- Медицинские тексты и расписания не прошли клиническую верификацию в рамках разработки каталога.
- Ручная проверка на физических устройствах и полная проверка экранным диктором ещё не выполнены.
